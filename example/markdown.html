Markdown 扩展示例 Alpha ​

本页展示了本文档提供的 Markdown 扩展功能。 VitePress所支持的 Markdown 扩展功能请查看VitePress官方文档。

词语释义 (Abbr) Dependency ​

此功能由markdown-it-abbr提供支持，此功能用于定义词语释义。

HTML 规范由 W3C 负责维护。

md
*[HTML]: 超文本标记语言（Hyper Text Markup Language）
*[W3C]: 万维网联盟（World Wide Web Consortium）

HTML 规范由 W3C 负责维护。

内部链接（Bi-directional links）Dependency ​

此功能由@nolebase/markdown-it-bi-directional-links提供支持，此功能用于创建文档内部链接。

component

自定义链接名称

还支持支持粗体、斜体 和代码

还可以自定义 HTML

md
[[component]]

[[component|自定义链接名称]]

[[component|还支持支持**粗体**、*斜体* 和`代码`]]

[[component|<span style="color: red;">还可以自定义 HTML</span>]]

更多使用方式可以前往@nolebase/markdown-it-bi-directional-links文档查看

图片组（Image group）Dependency ​

此功能由@miletorix/vitepress-image-group提供支持，此功能用于展示多张图片。

md
<ImageGroup :sources="['/img/tutorial/modpack/translation/pcl1.png','/img/tutorial/modpack/translation/pcl2.png']" type="auto"/>

更多使用方式可以前往@miletorix/vitepress-image-group文档查看
